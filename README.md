## INSTALLATIONS

Requires Python 3.9+

In the terminal run the following to run the project

python3 -m venv ChessVenv (to run the app in a virtual environment. You can name the venv anything)
source ChessVenv/bin/active (for bash)
pip install glfw
pip install PyOpenGL PyOpenGL_accelerate

python3 chess_3d.py (to finally run the project)
